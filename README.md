# Introduction to Programming Using C++ — Level 2

This repository contains my learning progress, exercises, and practice projects from Introduction to Programming Using C++ — Level 2 by Programming Advices.

## About the Course

This course builds on the programming foundations, algorithms, problem-solving, and clean-code skills developed in previous courses.

It focuses on understanding how C++ programs work internally, debugging code, managing memory, and writing more reliable and maintainable programs.

## Topics Covered

- Debugging with breakpoints and watches
- Advanced functions, overloading, default parameters, and recursion
- Variable lifetime and storage duration
- Pointers and references
- Dynamic memory allocation using `new` and `delete`
- Stack and heap memory
- Arrays, vectors, and iterators
- Creating reusable C++ libraries
- File handling
- Exception handling
- Date and time operations
